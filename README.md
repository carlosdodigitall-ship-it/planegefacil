# Planeje Fácil

Landing page responsiva para uma plataforma de gestão financeira.

## Estrutura

- `index.html`: página de apresentação completa, com CSS e JavaScript próprios no mesmo arquivo.

## Desenvolvimento local

Abra `index.html` no navegador ou sirva a pasta com um servidor HTTP estático.

## Deploy na Vercel

Configure o projeto para apontar para este repositório e use a raiz do repositório como Root Directory. Como esta landing page é estática, não é necessário comando de build nem diretório de saída. Se o projeto Vercel estiver configurado para Vite com comandos obrigatórios, ajuste as configurações de build para implantação estática.

## Antes de publicar

- Conectar os botões de acesso à rota real de login/cadastro.
- Confirmar funcionalidades, preços, termos, privacidade e canais de suporte reais.
- Substituir os números demonstrativos do painel por dados identificados como exemplos (atualmente já são ilustrativos).
